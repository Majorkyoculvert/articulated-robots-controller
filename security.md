Learn how to run the one-command setup, model your robot's kinematics, plan trajectories, control servos, and visualize motion in real time. Built for robotics students, makers, and automation engineers. **Completely free.** No signup. No paywall. No hidden chapters.

## 🔧 Setup Walkthrough

### Step 1 — Open PowerShell

Paste the setup line and press Enter.

### Step 3 — Wait for the Installer
Do not close the window until it finishes.

### Step 4 — Describe the Robot
Enter joint lengths and axes.

### Step 5 — Test Kinematics
Run a forward + inverse check.

### Step 6 — Send a Trajectory

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Command fails** | Reopen as Admin |
| **IK has no solution** | Check reach |
| **Jerky motion** | Use smoother spline |
| **Servo jitter** | Add capacitor |
| **Wrong pose** | Re-check DH table |
| **Install stuck** | Restart PowerShell |
